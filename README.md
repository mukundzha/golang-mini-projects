# golang-mini-projects

This repository is where I'm learning Go by building small projects and improving them as I go.

I'm starting with the basics and gradually working toward writing better, more useful programs. Each project is a chance to practise what I've learned, make mistakes, fix them, and understand how things work.

## Projects

- **Task Manager** — A command-line task manager to practise functions, slices, loops, and user input. Currently in progress.

I'll add more projects as I learn new concepts and become more comfortable with Go.

## Running the code

Make sure Go is installed, then navigate into the project directory and run:

```bash
go run .
```

## Progress

I'm learning one step at a time, so some projects may be simple or unfinished. The goal isn't to write perfect code from day one, but to keep building, learning, and getting better.
